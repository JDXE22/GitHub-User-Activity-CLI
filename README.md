# GitHub User Activity CLI

A simple command-line tool to fetch and display GitHub user activity in a straightforward, readable format.  

---

## ✨ Features

- View a user's recent GitHub activity directly from your terminal
- Supports fetching commits, pull requests, issues, and more
- Clean, easy-to-read output
- 100% JavaScript – no dependencies on other languages

---

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v14 or newer recommended)
- A GitHub personal or test username

### Installation

Clone this repo and install dependencies:

```bash
git clone https://github.com/JDXE22/GitHub-User-Activity-CLI.git
cd GitHub-User-Activity-CLI
npm install
```

### Usage

```bash
node index.js <github-username> 
```
